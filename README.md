🚀 Como Rodar o Projeto (React + Vite/CRA)
Este guia prático vai te ajudar a configurar o ambiente e rodar a aplicação na sua máquina local.
📋 Pré-requisitos
Antes de começar, você precisará ter o Node.js instalado em seu computador.
 * Node.js (LTS): Baixar aqui
🛠️ Passo a Passo
1. Clonar o Repositório
Primeiro, baixe a pasta do projeto ou clone o repositório em uma pasta local:
git clone https://github.com/seu-usuario/seu-repositorio.git

(Se você baixou o .zip, basta extrair o conteúdo na pasta de sua preferência).
2. Acessar a Pasta
Abra o Prompt de Comando (CMD) ou o Terminal e navegue até a pasta onde o projeto foi extraído:
cd nome-da-pasta-do-projeto

3. Verificar a Instalação do Node/NPM
Para garantir que o Node está pronto para uso, digite os comandos abaixo:
 * node -v (Verifica a versão do Node)
 * npm -v (Verifica a versão do gerenciador de pacotes)
4. Instalar as Dependências
Mesmo com o Node instalado, é necessário baixar as bibliotecas do projeto (a pasta node_modules). Para isso, execute:
npm install

5. Rodar a Aplicação
Agora, vamos subir o servidor local para visualizar o site:
npm run dev

(Caso seu projeto tenha sido criado com Create React App, o comando pode ser npm start).
🌐 Acessando o Site
Após o comando acima, o terminal exibirá um link local, geralmente:
> Local: http://localhost:5173/ ou http://localhost:3000/
> 
Basta copiar esse endereço, colar no seu navegador e o site estará rodando!
